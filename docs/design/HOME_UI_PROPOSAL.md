# Sable home UI proposal (BBOS 10 and BBOS 7): approved

The owner's approved home and navigation proposal for the Q25 (720x720), 10 pages:
[`artifacts/sable-home-ui-proposal.pdf`](artifacts/sable-home-ui-proposal.pdf).

Pages 1 to 4 and 8 show the BBOS 10 home: Active Frames, the app page, the application menu
(Edit Home, Search, Wallpaper, Settings) and Hub with the menu on the right and tabs at the bottom.
Pages 5 to 7 show the BBOS 7 home: icon grid with the Favourites drawer, the Menu key's full menu
(Switch Application first, the focused icon's lines, then Maximise Panel, Add Folder, Manage Panels,
Show All, Options) and the 3 x 3 trackpad-hold grid. Page 9 is the key map for both profiles
(Menu, Hold Menu, Back, End, Call, Trackpad, Trackpad hold, type a letter, touch). Page 10 is the
per-area comparison table with where each part lives and its status.
