merged Utilities / Notes / Recorder UX contract.

## Visual states

The SVG must include these four visible states:

```text
VISUAL_STATE_1=UTILITIES_HOME
VISUAL_STATE_2=NOTES_EDITOR
VISUAL_STATE_3=RECORDER_ACTIVE_REVIEW
VISUAL_STATE_4=CLOCK_CALCULATOR_TASKS
```

### State 1 — Utilities Home

Required visual cues:

```text
UTILITIES_HOME=PASS
ACTIVE_UTILITY_VISIBLE=PASS
RECENT_NOTE_TILE_VISIBLE=PASS
RECORDER_TILE_VISIBLE=PASS
NEXT_ALARM_TIMER_TILE_VISIBLE=PASS
CALCULATOR_TILE_VISIBLE=PASS
TASKS_TILE_VISIBLE=PASS
OPTIONAL_PROVIDER_CARD_AREA_VISIBLE=PASS
```

The screen must read as a compact daily utility dashboard rather than another
launcher or app drawer.

### State 2 — Notes Editor

Required visual cues:

```text
NOTES_EDITOR=PASS
NOTE_LIST_OR_RECENTS_VISIBLE=PASS
CURRENT_NOTE_EDITOR_VISIBLE=PASS
CHECKLIST_OR_STRUCTURED_LINE_EXAMPLE_VISIBLE=PASS
SEARCH_OR_COMMAND_DOCK_VISIBLE=PASS
TEXT_INPUT_FOCUS_VISIBLE=PASS
TEXT_INPUT_ALWAYS_WINS_VISUALIZED=PASS
```

The current note must remain visible. Older notes may be paged or searched, but
the current note must not require continuous scrolling to rediscover.

### State 3 — Recorder Active / Review

Required visual cues:

```text
RECORDER_ACTIVE_REVIEW=PASS
ACTIVE_RECORDING_STATE_VISIBLE=PASS
DURATION_VISIBLE=PASS
WAVEFORM_OR_LEVEL_VISIBLE=PASS
MARKER_OR_TRANSCRIPT_AREA_VISIBLE=PASS
SAVE_EXPORT_DELETE_ACTIONS_VISIBLE=PASS
MIC_PRIVACY_INDICATOR_VISIBLE=PASS
NO_HIDDEN_BACKGROUND_RECORDING=PASS
```

The artifact must make recording state obvious. There must be no visual pattern
suggesting silent, hidden or background recording.

### State 4 — Clock / Calculator / Tasks

Required visual cues:

```text
CLOCK_CALCULATOR_TASKS=PASS
NEXT_ALARM_VISIBLE=PASS
ACTIVE_TIMER_OR_STOPWATCH_VISIBLE=PASS
CALCULATOR_EXPRESSION_AND_RESULT_VISIBLE=PASS
CONVERTER_HINT_VISIBLE=PASS
OPEN_TASKS_VISIBLE=PASS
HISTORY_IS_EXPLICIT_NOT_PRIMARY=PASS
```

Calculator/Converter, Clock and Tasks can share a compact utility workspace, but
the active value/result/timer/task must always be visible.
