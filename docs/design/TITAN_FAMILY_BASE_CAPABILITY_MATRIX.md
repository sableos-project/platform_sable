## Purpose

This document defines which manual-derived capabilities may be treated as shared Titan-family base UX/features for SableOS N0 validation, and which capabilities remain device-specific or hardware/HAL-gated.

Titan 2 Elite manual confirmation allows several features that were previously held behind Titan 2 Elite validation to move into a shared Titan-family base profile. Shared base status means the UX/product requirement may be planned for both Titan 2 and Titan 2 Elite. It does not prove HAL availability, kernel support, vendor service availability, carrier support, or flash readiness.

## Network Manager authority

The Titan manuals describe per-app cellular/WLAN style controls. SableOS must not implement a duplicate network-control stack. The implementation authority remains the Settings-owned Sable Network Manager already used for Panther/R9.

```text

NETWORK_CONTROL_AUTHORITY=SETTINGS_OWNED_SABLE_NETWORK_MANAGER
NETWORK_CONTROL_IMPLEMENTATION=REVOCABLE_ANDROID_PERMISSION_INTERNET
```
