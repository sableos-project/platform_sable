# Sable Connectivity / OTG / NFC / Cast / Compatibility UX

## Purpose

Define the SableOS connectivity and device-compatibility surface for Titan 2-class devices: USB file transfer, USB OTG, Bluetooth transfer, NFC, Cast, Hotspot/Tethering, app rotation control and Mini Mode / compatibility display handling.

This PR groups remaining manual-derived connectivity and compatibility features into one design contract instead of fragmenting them across many small PRs.

```text
CONNECTIVITY_OTG_NFC_CAST_COMPATIBILITY_UX=YES
USB_FILE_TRANSFER_INCLUDED=YES
USB_OTG_INCLUDED=YES
```
