# Sable Sub-screen / Shortcut Keys / Keyboard Gestures UX

## Purpose

Define the Titan 2 hardware identity layer: rear sub-screen companion modes, Func1/Func2, PTT behavior, programmable Sym/Fn keys, Magic key shortcuts, Space-key actions, letter-key shortcuts, media-key behavior, keyboard gesture scroll assistant, and cursor assistant.

This contract is intentionally separated from app UI contracts because these behaviors affect every surface.

```text
SUBSCREEN_SHORTCUT_KEYBOARD_UX=YES
TITAN2_HARDWARE_IDENTITY_LAYER=YES
SUBSCREEN_COMPANION_MODES=YES
SHORTCUT_KEYS_INCLUDED=YES
KEYBOARD_GESTURES_INCLUDED=YES
TEXT_INPUT_ALWAYS_WINS=YES
BUILD_CODE_CHANGED=NO
DEVICE_CODE_CHANGED=NO
FLASH_ENABLEMENT=NO
```

## Sub-screen posture

The rear sub-screen should be treated as a curated companion surface, not a general app-mirroring display.

```text
SUBSCREEN_COMPANION_MODES=YES
SUBSCREEN_ARBITRARY_APP_MIRRORING=NO
SUBSCREEN_TEXT_INPUT=NO
SUBSCREEN_EDITING_INPUT=NO
SUBSCREEN_SPECIAL_SHAPE_AWARE=YES
SUBSCREEN_RESOLUTION_AWARE=YES
```
