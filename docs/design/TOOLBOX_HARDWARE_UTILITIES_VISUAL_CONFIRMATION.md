# Toolbox / Hardware Utilities Visual Confirmation

## Target

Validate a Titan 2-first visual direction for the hardware utility layer.

```text
VISUAL_CONFIRMATION=TOOLBOX_HARDWARE_UTILITIES
TARGET_DEVICE=TITAN2
SQUARE_DISPLAY=YES
PHYSICAL_KEYBOARD=YES
SUBSCREEN_COMPANION=YES
```

## Visual states

```text
VISUAL_STATE_1=TOOLBOX_HOME_SENSOR_GRID
VISUAL_STATE_2=MEASURE_COMPASS_LEVEL_PROTRACTOR
VISUAL_STATE_3=IR_REMOTE_DEVICE_CONTROL
VISUAL_STATE_4=MEDIA_FM_RADIO_HARDWARE_GATED
```

## State 1: Toolbox Home Sensor Grid

Required visual elements:

```text
TOP_TELEMETRY_STRIP=YES
TOOLBOX_TITLE=YES
CAPABILITY_STATUS_BADGES=YES
LAST_USED_TOOLS=YES
MEASURE_ROW=YES
LIGHT_CAMERA_ROW=YES
MOTION_FITNESS_ROW=YES
REMOTE_RADIO_ROW=YES
BOTTOM_COMMAND_DOCK=YES
```

Do not show unsupported hardware tools as normal app icons.

```text
UNPROVEN_CAPABILITY_VISIBLE_AS_NORMAL_TOOL=NO
DIAGNOSTIC_ONLY_UNAVAILABLE_STATE=YES
```
