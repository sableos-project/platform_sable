# Browser / WebView visual confirmation

Status: source-controlled design validation checklist for the Titan 2 Browser / WebView UX.

Visual artifact:

```text

```

## Required visual states

```text
VISUAL_STATE_1=BROWSER_START_SEARCH
VISUAL_STATE_2=BROWSER_READER_PAGE_MODE
VISUAL_STATE_3=TAB_OVERVIEW_PRIVACY
VISUAL_STATE_4=WEBVIEW_PERMISSION_EXTERNAL_OPEN
```

The artifact must show Browser and WebView on the Titan 2 square display with physical keyboard. It must not use a stretched slab-phone target.
