# Sable Toolbox / Hardware Utilities / Remote / Radio UX

## Purpose

Define the SableOS hardware-utility layer for Titan 2 first, Titan 2 Elite after independent validation, and Q27 only when matching retail hardware is proven.

This contract is derived from the Titan 2 user-guide capability set and the observed stock Toolbox grid. It must not become a generic Android utility grab bag. Each feature must be backed by a declared device capability, sensor, framework API, vendor service, HAL path, or explicit future-gate.

```text
TOOLBOX_HARDWARE_UTILITIES_UX=YES
TITAN2_TOOLBOX_APPS=YES
TITAN2_IR_REMOTE=YES
SABLE_MEDIA_FM_RADIO_GATE=YES
DEVICE_PROFILE_REQUIRED=YES
TITAN2_ELITE_INDEPENDENT_VALIDATION=YES
Q27_RETAIL_HARDWARE_REQUIRED=YES
SUBSCREEN_COMPANION_MODES=YES
KEYBOARD_FIRST_TOOLBOX=YES
BUILD_CODE_CHANGED=NO
DEVICE_CODE_CHANGED=NO
FLASH_ENABLEMENT=NO
```

## Product posture

Sable Toolbox exists for practical device-native tasks that benefit from Titan-class hardware: sensors, camera, flashlight, microphone, GPS, rear sub-screen companion modes, physical keys, IR transmission, and media hardware when proven.

```text
TOOLBOX_IS_HARDWARE_UTILITY_LAYER=YES
TOOLBOX_IS_NOT_DAILY_NOTES_LAYER=YES
TOOLBOX_IS_NOT_SETTINGS_DUMP=YES
```

Toolbox Home is a grid of hardware utilities with current capability state visible. Disabled or unproven tools are visible only in diagnostics/developer profile mode, not as broken app icons.

```text

```


Keyboard controls:

```text
C=Calibrate
R=Reset
H=Hold_reading
S=Save_reading
I=Info
Back=Exit_tool
```
